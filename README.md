# jiya-dhiman.github.io

Personal portfolio site for Jiya Dhiman, Computer Science student at Purdue University.

**Live site:** [jiya-dhiman.github.io](https://jiya-dhiman.github.io)

## About

This site covers my background, coursework, research and campus involvement, work experience, and a selection of software projects spanning full-stack web apps, real-time multiplayer systems, and desktop applications.

## Built with

- HTML, CSS, and vanilla JavaScript — no build step or framework
- [Fraunces](https://fonts.google.com/specimen/Fraunces), [Inter](https://fonts.google.com/specimen/Inter), [Caveat](https://fonts.google.com/specimen/Caveat), and [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) from Google Fonts
- [Boxicons](https://boxicons.com/) for iconography
- Hosted with [GitHub Pages](https://pages.github.com/)

## Structure

```
.
├── index.html        # Home page: about, education, experience, leadership, skills
├── projects.html      # Featured projects
├── style.css           # Shared styling
├── script.js            # Scroll reveal, typewriter effect, nav behavior
├── resume.pdf           # Downloadable resume
└── images/
    └── profile.jpg      # Headshot
```

## Running locally

Clone the repo and open `index.html` in a browser, or serve it with any static file server, for example:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
